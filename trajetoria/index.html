Ferramentas de trabalho

Não acredito em percentuais de proficiência. O que segue é o que uso de fato, agrupado pelo tipo de problema, com a indicação de onde isso pode ser visto.

  • Computação científica

    Aritmética de bolas e intervalar com Arb/FLINT (python-flint) quando um número precisa ser um certificado, não uma estimativa; mpmath para precisão arbitrária; NumPy e SciPy para estatística e bootstrap. As computações pesadas são escritas em Rust (programação dinâmica sobre conjuntos de bits) e em C com OpenMP (enumeração de árvores).

    Repositórios de reprodutibilidade dos preprints.

  • Inteligência artificial

    Recuperação híbrida (densa e lexical, fusão por postos, reordenação com cross-encoder), LangGraph, avaliação com conjuntos de referência e ablações; processamento de imagens com OpenCV, OCR com EasyOCR e métricas com scikit-learn.

    Pipeline de RAG e preprint de OCR de placas.

  • Linguagens

    Python para pesquisa e dados; Kotlin e Java no Android; TypeScript, JavaScript e PHP na web; C, C++ e Rust onde desempenho ou hardware exigem; SQL em tudo; LaTeX para escrever.

  • Bancos de dados

    PostgreSQL é a base da maior parte do que construo, incluindo busca textual e vetorial (pgvector) na mesma instância. Também MySQL/MariaDB, SQLite e Room no Android, Redis e MongoDB.

  • Android

    Kotlin, Jetpack Compose, Room, DataStore, Hilt e WorkManager, em aplicativos que funcionam sem conexão por projeto.

    Sete aplicativos publicados no Google Play.

  • Web e infraestrutura

    Node.js, HTML e CSS sem intermediários quando o problema permite (este site é um exemplo), Docker, Linux, Git e integração contínua com GitHub Actions.

  • Sistemas embarcados

    Microcontroladores Atmel/AVR, Arduino, rádio LoRa, eletrônica de baixo consumo e desenho de placas no Altium Designer.

    Trabalho na MR Automação Industrial.

Idiomas

Português, língua materna, e inglês, em que escrevo os artigos.
